# Instagram Clone Frontend

Instagram Clone Frontend built using **Next.js, React, and JavaScript**.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Technologies Used

- Next.js
- React
- JavaScript
- CSS

## Project Description

This project is an Instagram-inspired frontend with features such as user authentication, profiles, posts, search, and chats.
